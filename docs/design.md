# 视觉与交互设计：研究工作台

## 设计目标

用户打开后三秒能回答：这是一个把公开技术信号变成“待人工验证的商业假设”，同时复盘“我本人学会了什么”的周报工作台。不是资讯门户，不是 CRM，也不是 Agent 自我表扬墙。

## 独立构图

采用“证据账本”构图：宽带页眉后，主体是左侧连续审阅流、右侧本周工作台。商机和成长不用互相孤立的圆角卡片，而用细分隔线串成可连续扫描的记录。每条商机都按“公开信号 → 商业假设 → 下一动作”阅读；归档项目作为反例留在同一账本中。

## 紧凑设计 Token

- 纸面 `#F7F3EC`；工作面 `#FDFBF7`；主墨 `#262823`；次墨 `#6E776E`；细线 `#E3DED4`。
- 强调只用一个森林绿 `#335747`；反例使用低饱和陶土色 `#9A5F4A`，不做大面积警示。
- 正文 Noto Sans SC，数字/日期/短标签 Maple Mono；本地 WOFF2，无外部字体请求。
- 圆角 0 / 4 / 999（仅状态小标签）；阴影不用；渐变不用。
- 最大内容宽 1180px；正文 16px；页眉主标题 40px；移动端正文不小于 15px。

## 必要交互

- 自定义名称、方向、周期；保存到 localStorage。
- 新增商机与成长；字段必填；来源仅允许 HTTPS。
- 商机状态在“待审核 / 进入跟进 / 暂缓”之间切换。
- 导出当前状态的 Markdown；可清空本地修改回到演示快照。
- 所有表单有标签、错误提示、键盘焦点与 Escape 关闭。

## 反模板自审

- 不是 hero + 三列功能卡 + CTA；主体直接是真实工作记录。
- 不用大数字装饰；计数只服务于审核进度。
- 不用渐变、玻璃拟态、漂浮几何、随机插图或无意义动效。
- 不复制个人主页的终端、像素字、命令行、三色圆点、方格纸。
- 绿色不是模型实力排名，只代表“可继续人工验证”；陶土色只用于反例。
