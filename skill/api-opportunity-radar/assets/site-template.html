方法边界

事实与假设分栏

官方仓库、公开文档是事实来源；买方角色、需求与下一动作是待证伪假设，二者不混写。

成长与流水账分栏

只有行为前后变化、证据定位与下一实验同时存在，才记为成长；工具调用次数本身不是能力。
